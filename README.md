# Dasterkhwan | دسترخوان

Restaurant website (English + Urdu) — simple HTML, CSS, JavaScript.

## Files
- `index.html` — page structure
- `styles.css` — design
- `script.js` — menu items, prices, and English/Urdu text

## Edit karna
- **Menu / prices:** `script.js` mein `MENU` list
- **Phone / WhatsApp:** `index.html` mein `+92 300 0000000` aur `wa.me/923000000000`
- **Address / timings:** `script.js` mein `c_address_val` aur `c_hours_val`

## Chalana
`index.html` ko browser mein double-click karke kholen.

## GitHub par upload
```
git init
git add .
git commit -m "Dasterkhwan website"
git branch -M main
git remote add origin https://github.com/AhmadStoreShahdra/dasterkhwan.git
git push -u origin main
```
Free hosting: GitHub repo → Settings → Pages → Branch: `main` → Save.
